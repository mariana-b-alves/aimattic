Como Utilizar Strings em Python - Textos no Python

Fala Galera! Nessa aula nós vamos apresentar a vocês Python String! Strings nada mais são do que textos no Python.

Então hoje nós vamos te mostrar as Strings no Python e como você pode trabalhar com elas.


String no Python é um tipo de informação, assim como temos os números, temos os textos, mas é chamado de string todo e qualquer texto.

Isso é importante, pois nos permite fazer alguns tratamentos de informações, além do tratamento de números que é um pouco diferente.


Além de te mostrar como utilizar textos em Python (ou como utilizar strings em Python), nós vamos te mostrar métodos do Python que funcionam em string, ou seja, métodos da linguagem que te permitem o tratamento de textos.


Em seguida nós vamos te mostrar alguns métodos específicos de string, que são métodos exclusivos para o tratamento de strings.


Para finalizar nós vamos disponibilizar uma cartilha string em Python para te auxiliar com esse tema que é bastante utilizado dentro do Python.


E aí, curioso para aprender a trabalhar com textos dentro do Python? Então vamos a aula para não perder nada!
